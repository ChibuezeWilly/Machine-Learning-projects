# Machine Learning Projects

A collection of applied machine learning projects using scikit-learn and related Python tools. The notebooks cover supervised prediction, text classification, forecasting, clustering, and customer analytics, from data preparation through model evaluation.

## Projects

| Project | Focus |
|---|---|
| [Customer churn](customer_churn/) | Predicting customer churn from customer records. |
| [Dynamic pricing](Dynamic%20Pricing%20Engine/) | Estimating price responses for a dynamic pricing use case. |
| [Employee attrition](Employee_Attrition_Project/) | Identifying employee attrition risk. |
| [Energy consumption forecasting](Energy%20Consumption%20Forecasting/) | Forecasting energy use from historical measurements. |
| [Support ticket classifier](Support%20ticket%20classifier/) | Classifying support requests by topic. |
| [Customer segmentation](customer_segmentation/) | Clustering customer behavior and interpreting segments. |
| [Estate price prediction](Estate_prediction/) | Predicting property prices from property features. |
| [Loan default prediction](Loan_prediction_system/) | Assessing loan default risk from applicant and loan data. |
| [User behavior analysis](user_behaviour/) | Exploring patterns in user activity and behavior. |
| [Ride fare prediction](ride_fare_prediction/) | Predicting ride cost from trip details. |

## Tools

Python, pandas, NumPy, matplotlib, scikit-learn, and Jupyter Notebook.

## How to explore

Open a project's notebook in Jupyter or Google Colab. Run the cells in order and review the data preparation, model choices, and evaluation in that notebook. Some projects include a small CSV dataset alongside the notebook. Install the packages imported by a notebook in your Python environment before running it.
